# MargyT reference: final gesture and sponsor changes
Inspected user-supplied MargyT-main (2).zip: SponsorBlock.java, PlayerTools.java, TabBadges.java, TabCount.java, Text.java, Badges.java, dexpatch.py, ADDITIONAL-TERMS.md. GPL-3.0 with additional attribution terms; independent adaptation to TTMLonger. MargyT recognizes author-read ads with server-marked millisecond segments and audio fingerprints, not a phrase dictionary. This implementation uses only opt-in read-only lookup of video IDs at the archive's documented /api/sb endpoint. No authentication, audio downloads, fingerprint lookup or submission. No claim that remote service access or 47.9.3 controller signatures work. Native progress callback and model ID are checked before a bounded seek; undo is offered. The unread action is local/session-scoped and does not send native read receipts, matching TabBadges semantics; 99+ cannot reveal subsequent growth. Two-finger settings entry is removed; normal sticker ACTION_UP handling remains. Home long press remains. Four pure regression checks were added. No live feed validation.
