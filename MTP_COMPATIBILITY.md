# MTP compatibility (experimental)
Reference: user-supplied MargyT archive docs/plugins.md, public MargyPlugin and PluginContext signatures, PluginPackage.java, Plugins.java. Independently written ABI bridge. The host accepts the documented flat archive, validates inflated sizes, min_api and entry, approves an exact SHA-256 content digest before executing, and uses InMemoryDexClassLoader on API 26+. No remote catalog/agent service or automatic approval. Plugins are trusted in-process code; there is no sandbox. Disabling or catching an exception does not undo side effects or terminate arbitrary plugin threads.
Public API 1–5 method signatures are present, with adapters for lifecycle, settings, color, region, text, name, feed, account, UI and downloads. Semantics differ: onStart is at TTMLonger boot (attach or later fallback), onScreen is activity-based, account events currently checked on resume, only known feed getter and resource color paths are hooked, current video metadata depends on matching visible model, no complete MargyT private-class ABI. Network helpers are HTTPS-only with bounded responses. Android <26 is unsupported. Icon file is stored but not displayed in manager. Two initial regression assertions are not end-to-end DEX tests. Not guaranteed compatible with every existing .mtp. MargyT GPL-3.0 plus additional terms remain applicable to its source; no wholesale source import.
