# Additional feature adaptation
Reference archive: MargyT MessageTimes.java, Comments.java / CommentSelection.java, FeedBlacklist.java, Backup.java, DownloadTasks.java and dexpatch.py. Independent adaptations for TTMLonger Xposed; no wholesale source import. Message clock and comment menu rely on exact reference-version class/method signatures and may be absent in 47.9.3; real UI tests are still required. Blacklist is device-local, capped at 50 numeric UIDs and filters only the feed getter without mutating lists; this may miss direct field reads and may also affect other lists using FeedItemList. Backup uses SAF and a fixed allowlist (no account IDs, message content, tokens, user block lists or A/B flags); only selected settings are backed up, not all glass profiles. Video/photo cards display determinate progress when bytes or slide count is known, indeterminate otherwise. Six new runtime checks cover pure logic, not live UI.
