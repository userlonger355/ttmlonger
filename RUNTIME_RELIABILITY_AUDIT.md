# Runtime reliability audit
Reviewed current implementation and reopened MargyT archive PlayerTools.java, NativeRead.java and MessageTimes.java. Fixed non-main player callbacks with coalescing and per-ID network failure backoff; MTP feed transforms no longer write back to the native page; remote badge toggle rebuilds effective marks without the shared catalog; message clock adds LJJIZ fallback, incoming alignment and weak state cache; inbox badge recognizes numeric suffixes and removes inactive pre-draw listener. Earlier avatar mask fix is retained. The original native fork remains separate.
Known outstanding: real feed guest smoke was skipped, actual 47.9.3 obfuscated anchors may differ; offline count validation, voice messages and chat appearance depend on native/server behavior; author-specific advertisement service availability is not proven; avatar shapes and glass navigation require on-device test; Motion Blur external MTP not supplied.
