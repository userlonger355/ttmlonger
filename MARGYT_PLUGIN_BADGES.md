# Plugin and badge compatibility
Source reference: user-provided MargyT archive docs/plugins.md, examples/commands-plugin.json, Badges.java and badges.json. MargyT supports executable .mtp DEX with no sandbox; TTMLonger implements a limited declarative JSON subset (window action only), local installation, review, off by default, enable and remove. No code execution, network, or .mtp compatibility. MargyT catalogue import accepts badges[].id/colour/users, renders an independently drawn neutral hexagonal glyph, and ignores image paths, links, and remote metadata. This is not the TikTok You badge format or exact artwork; no TikTok You-specific badge implementation was found in the supplied archive (only the simple-feed reference). The imported catalogue coexists with local and shared TTMLonger rules, capped at four visible badges; app restart may be needed. Three new pure checks; actual rendering remains unverified. MargyT license and attribution terms apply to original source; no wholesale source import.
