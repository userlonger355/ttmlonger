## Как получить тестовую сборку

1. Открыть Actions → Build TTMLonger → нужный запуск.
2. Скачать артефакт TTMLonger (APK модуля) и TTMLonger-build-info (SHA-256 и коммит).
3. Проверить SHA-256. Устанавливать на отдельное тестовое устройство через LSPatch по инструкции README.
4. Не публиковать сторонний APK TikTok, пароли, коды авторизации, содержимое личных чатов.
